Setup & requirements

What this local pipeline needs, and a one-shot Claude Code prompt that installs it all.

Requirements

  • Node 18+ — runs the local server and the Plaud MCP (npx @plaud-ai/mcp).
  • ffmpeg — converts audio to 16 kHz mono WAV. brew install ffmpeg
  • whisper.cpp (whisper-cli) — local transcription. brew install whisper-cpp
  • Whisper model — ggml-small.en.bin at ~/.config/claude-watch/models/
  • Plaud login — one-time browser OAuth; token auto-refreshes at ~/.plaud/tokens-mcp.json
  • Notations token — the app's MCP token, via NOTATIONS_TOKEN / FIELDLINES_TOKEN, or reused from the plaud-sync agent. Endpoint notations.app/api/mcp/mcp
  • Diarization (optional) — sherpa-onnx venv at ~/.config/plaud-diarize/ + ~/bin/plaud-diarize.py. Only needed for speaker labels.
  • AI summary (optional) — the add_iteration companion is added by Claude; it needs an LLM, so it isn't automated by the server.

Files this uses

  • ~/Desktop/plaud-pipeline.html — the UI (this app).
  • ~/bin/plaud-pipeline-server.mjs — zero-dep server: grab (Plaud MCP), transcribe, upload (Notations MCP).
  • ~/bin/plaud-transcribe.sh — download → ffmpeg → whisper → formatted note.
  • ~/Library/LaunchAgents/com.stefan.plaud-pipeline.plist — login service on port 8791 (RunAtLoad + KeepAlive).

Install it with Claude Code

Paste this into Claude Code. It will install the prerequisites and wire up the service.

claude-code-install-prompt 
Set up the "Plaud → Notations upload" local pipeline on this Mac.

1. Install prerequisites (Homebrew): `brew install ffmpeg whisper-cpp`. Confirm Node 18+ is present.
2. Download the Whisper model ggml-small.en to ~/.config/claude-watch/models/ggml-small.en.bin.
3. Ensure these files exist (create if missing):
   - ~/bin/plaud-transcribe.sh  (download|--audio -> ffmpeg 16kHz mono WAV -> whisper-cli small.en -> formatted Markdown note; optional --diarize --speakers N via sherpa-onnx).
   - ~/bin/plaud-pipeline-server.mjs  (zero-dep Node HTTP server: serves the UI; GET /recordings and POST /run drive the Plaud MCP via `npx -y @plaud-ai/mcp@latest`; POST /run-upload accepts a browser-picked file; on success it POSTs create_post to the Notations MCP at https://notations.app/api/mcp/mcp, folder "Meetings", tags plaud/recording, published:false).
   - ~/Desktop/plaud-pipeline.html and ~/Desktop/plaud-setup.html  (the UI + this page).
   Make plaud-transcribe.sh executable.
4. Log into Plaud once: `npx -y @plaud-ai/mcp@latest install` (browser OAuth; token stored at ~/.plaud/tokens-mcp.json, auto-refreshes).
5. Provide the Notations MCP token. The server reads NOTATIONS_TOKEN, else FIELDLINES_TOKEN, else the FIELDLINES_TOKEN inside ~/Library/LaunchAgents/com.fieldlines.plaud-sync.plist (the app's static MCP_API_TOKEN). Ensure one is available.
6. Install a launchd LaunchAgent com.stefan.plaud-pipeline that runs `/opt/homebrew/bin/node ~/bin/plaud-pipeline-server.mjs` with EnvironmentVariables PORT=8791 and PLAUD_HTML=~/Desktop/plaud-pipeline.html, RunAtLoad + KeepAlive true, logging to ~/Library/Logs/plaud-pipeline.log. Bootstrap it and verify http://localhost:8791 returns 200 and /recordings lists my Plaud recordings.
7. Optional: set up sherpa-onnx diarization in ~/.config/plaud-diarize/venv with ~/bin/plaud-diarize.py for speaker labels.

Note: port 8787 may be taken by another app — use 8791. Report anything that failed and how to finish it.
